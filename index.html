KONFIGURASI

Pengaturan

Atur aturan absensi dan pengelolaan data lokal.

Jam batas kehadiran

Scan sebelum batas masuk dianggap hadir; pada atau setelahnya dianggap terlambat.

Waktu pada prototipe ini mengikuti perangkat. Untuk penggunaan resmi, waktu harus ditentukan server.

Akhir periode absensi

Alfa hanya ditetapkan oleh admin setelah periode scan selesai, bukan otomatis ketika siswa belum scan.

Tindakan dicatat di riwayat admin lokal. Pastikan periode absensi sudah ditutup.

Data dan privasi

Prototipe lokalData hanya tersimpan di LocalStorage browser/perangkat ini. Data bisa hilang jika penyimpanan browser dibersihkan, tidak tersinkron antar perangkat, dan tidak aman sebagai sistem produksi.

Untuk operasional sekolah, gunakan backend dan database terpusat, autentikasi server, pencadangan, pencatatan audit, waktu server, pembatasan akses, serta izin/persetujuan yang sesuai untuk foto siswa.
